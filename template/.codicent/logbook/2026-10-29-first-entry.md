# First entry

This logbook is the repo's memory. It lives in git, in plain Markdown, so
any agent or human can read it with no special tooling.

How to use it:

1. Read `index.md` at session start, then entries relevant to your task.
2. Record decisions (`#decision`), tacit knowledge (`#tacit`), and releases
   (`#release`) using the files in `templates/`.
3. Update `index.md` in the same change. See `../CONTRACT.md` for the rules.
